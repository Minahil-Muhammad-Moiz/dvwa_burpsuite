# DVWA and Burp Suite Practical Report

**Subject:** Web Application Security Testing  
**Tools:** Docker, DVWA, Burp Suite, Linux  
**Target:** Localhost (127.0.0.1)

## 1. Objective

The objective of this practical was to deploy DVWA in a local Docker environment and understand HTTP request interception, request modification, response analysis and automated testing using Burp Suite.

## 2. Lab Environment

- Operating System: Linux
- Vulnerable Application: DVWA
- Deployment: Docker
- Browser: Firefox / Burp Browser
- Security Testing Tool: Burp Suite
- Target URL: http://localhost:8081

## 3. DVWA Installation

DVWA was deployed using the following Docker command:

`docker run --rm -it -p 8081:80 vulnerables/web-dvwa`

The application was accessed through the browser at http://localhost:8081.

## 4. Proxy and Request Interception

Burp Suite Proxy was configured using its built-in browser.
HTTP requests generated by DVWA were intercepted and examined.
The following components were observed:

- HTTP request method
- Request URL
- Headers
- Cookies
- Parameters
- Server response

## 5. Repeater Module

The Repeater module was used to resend captured HTTP requests.

Different harmless parameter values were tested to understand how server responses changed.

The following observations were recorded:

- HTTP status codes
- Response lengths
- Response content
- Server responses to modified requests

## 6. Intruder Module

The Intruder module was explored to understand automated HTTP request testing.

A harmless numeric parameter was selected and multiple test values were configured.

The results were compared based on response status and response length.

## 7. Results

The practical demonstrated:

1. Successful DVWA deployment.
2. Successful Burp Suite browser configuration.
3. HTTP request interception.
4. Request inspection and modification.
5. Repeated request testing using Repeater.
6. Payload configuration and result analysis using Intruder.

## 8. Conclusion

This practical provided hands-on experience with web application security testing.

It demonstrated how Burp Suite can intercept, inspect, modify and resend HTTP requests, and how its Intruder module can automate controlled parameter testing.
